Eliminate N+1 queries in the scheduler's mapped-task dependency evaluation. ``MappedTaskUpstreamDep`` no longer issues one query per task instance for its mapped upstreams (the run's unexpanded task instances are prefetched once per scheduling pass, and the query is skipped entirely when a mapped task has no real upstream dependency), ``get_mapped_ti_count`` is memoized per ``(node, run)`` within a scheduling pass instead of being re-resolved per map index, and mapped-task expansion no longer flushes or issues an existence-probe ``SELECT`` per created map index. This substantially reduces the database round-trips a scheduling decision makes for wide dynamic task mapping.
